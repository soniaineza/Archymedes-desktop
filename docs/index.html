Archymedes reads, edits, and runs commands in your workspace — and shows you everything: guarded execution, recoverable edits, explicit cost, durable history. Your keys, your machine, your terminal.

Get started → Source on GitHub

Review before you trust

An open-source coding agent for the terminal, with an IDE-grade desktop client. Every edit is snapshotted, diffable, and one keystroke from undo.

Guarded execution

Approval modes from “ask me always” to “just run it.” Spawned commands are confined to the workspace. Failed checks are shown as failed — green only means verified.

Recoverable edits

Every file the agent touches is snapshotted first. /diff shows the unified diff, /undo rolls it back. The desktop client reverts with one click.

Explicit cost

Live spend in your currency, priced from a dated per-model catalog with cached-token discounts. Models without pricing say so instead of guessing.

Durable history

Sessions are saved after every tool step, so a killed process resumes where it stopped — not where it started.

Your providers, your keys

Anthropic, OpenAI, Gemini, Grok, DeepSeek, Mistral, Groq, Ollama (local), any OpenAI-compatible endpoint, and free OpenRouter models with your own key. Keys stay on your machine.

16 languages

The interface speaks 16 languages out of the box: archymedes --language <code>.

See a turn

A real session shape — request, guarded edits, verification, review — as it renders in the terminal.

Quickstart

Node 22+ on macOS, Linux, or Windows.

  1. npm install -g archymedes-cli
  2. Run archymedes in your project, pick a provider, paste a key — stored locally, nothing proxied. <PROVIDER>_MODEL chooses a model.
  3. Give it a task: “fix the failing test in src/parser.ts.”
  4. Review with /task, inspect with /diff, undo with /undo.
  5. Prefer windows? Install Archymedes Desktop and open any folder as a workspace.
Honest status: the local, BYOK product is the release. Hosted services (Archymedes Cloud, the hosted free gateway) are in private beta and not part of it. Free mode (--free) needs your own OpenRouter key or a self-hosted gateway.
